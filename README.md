# Kajal Rekha — Personal Portfolio

A modern, responsive personal portfolio built with Next.js, TypeScript, and Tailwind CSS to showcase my projects, technical skills, and development journey.

## Features

- Modern UI: Clean, minimal, and professional design.
- Responsive Design: Optimized for desktop, tablet, and mobile devices.
- Hero Section: Introduction, social links, and quick navigation.
- Projects Showcase: Featured projects with live demos and GitHub repositories.
- Project Filtering: Filter projects by category, including SaaS, eCommerce, Full-Stack, AI, and Dashboard.
- Skills Section: Categorized technical skills across frontend, backend, database, and development tools.
- About Me: Professional introduction and development background.
- GitHub Highlights: Showcase public repositories and contribution activity.
- Contact Form: Get in touch through an EmailJS-powered contact form.
- Smooth Animations: Scroll-based animations using AOS.
- Toast Notifications: Interactive feedback using React Hot Toast.

## 🚀 Installation

Follow these steps to run the project locally.

1. Clone the repository

```bash
git clone https://github.com/kajal-rekha/personal-portfolio.git
```

2. Navigate to the project directory

```bash
cd personal-portfolio
```

3. Install dependencies

```bash
npm install
```

4. Configure environment variables

Create a `.env.local` file in the root directory and add your EmailJS credentials.

```env
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
```

Use the same variable names referenced in your EmailJS implementation.

5. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
